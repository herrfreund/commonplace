# Commonplace Book

A simple web page for saving passages from books, with my own notes.

## Rules for working on this project

- I'm learning to build. Explain what you're about to do in plain English before you do it.
- No jargon without defining it.
- Keep everything as simple as possible.
- Use plain HTML, CSS and JavaScript in one file (`index.html`). No frameworks.

## How it works

- Open `index.html` in a browser to use it.
- Entries are saved in the browser's localStorage, so they survive a refresh. They are stored only in that browser on that computer.
